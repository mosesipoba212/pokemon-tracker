# Pokémon Tracker

A competitive Pokémon team builder and analysis dashboard with real-time type matchup calculations, team recommendations, and strategic insights.

## Features

- **Pokémon Search & Analysis**: Look up any Pokémon with detailed stats, abilities, and type information
- **Team Builder**: Build your competitive team with up to 6 Pokémon
- **Type Matchup Analysis**: Real-time weakness and resistance calculations
- **Smart Recommendations**: AI-powered suggestions to fill team gaps
- **Move Analysis**: View competitive movesets and coverage options
- **Item Recommendations**: Get strategic item suggestions for each Pokémon
- **Dual Comparison**: Compare two Pokémon side-by-side with matchup analysis

## Tech Stack

- Pure HTML5, CSS3, and JavaScript (no frameworks)
- PokéAPI integration for Pokémon data
- Responsive design for desktop and mobile
- Modern CSS Grid and Flexbox layouts

## Local Development

Simply open `index.html` in a web browser:

```bash
# Using a local server (recommended)
python -m http.server 8000
# or
npx serve
```

Then navigate to `http://localhost:8000`

## Deployment

This project is deployed on Vercel. Any push to the main branch automatically triggers a new deployment.
